# שטראוס · מוקד המכירות · יחידה 04 – Salesforce: סביבת עבודה, דגשים והתראות

לומדת HTML ליחידה 04 בתכנית ההכשרה של מוקדני המכירות בשטראוס, לפי התסריט.

- קובץ אחד עצמאי: `index.html` (גופני Strauss, תמונות, צילומי מסך וצלילים מוטמעים בקובץ).
- במה 1200×675, מותאמת לכל גודל מסך.
- 18 מסכים: פתיחה, מה נלמד, מסך ניווט, סימולציות על צילומי Salesforce אמיתיים (מסך הבית, דוחות, ההתקשרויות שלי להיום, מסך ההתקשרות, דגש עצמי, הערה קבועה ללקוח, טיפול בהתראת מק"ט), סוגי ההתראות, הבחנה, תרגיל התאמה, 3 שאלות תרגול, סיכום וסיום.
- סרגל "מעבר לשקף" בתחתית לצורכי בדיקה (יוסר לפני ההפצה).
- בכל מסך הערות הפקה (`data-note`) לקראת ההמרה ל-Storyline.

לצפייה: פותחים את `index.html` בדפדפן.
